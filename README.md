# Калькулятор цены с учетом скидки и рассрочки на заданное количество месяцев

## Ключевые особенности

- Вычисляет итоговую цену с применением скидки
- Поддерживает возможность рассрочки выплат на заданное число месяцев

# Нормализация данных постов

Утилита, предназначенная для преобразования массива постов в нормализованную структуру, что позволяет эффективно получать доступ по ID

## Ключевые особенности

- Конвертирует массив в объект, обеспечивая быстрый доступ по ID
- Сохраняет оригинальный порядок элементов по их ID

# Извлечение данных о комментариях

Данный проект предназначен для асинхронного извлечения и отображения данных о комментариях с использованием API. Он обращается к публичному API jsonplaceholder и выводит информацию о комментариях, включая их ID и адрес электронной почты

## Ключевые особенности

Код выполняет HTTP-запрос к API https://jsonplaceholder.typicode.com/comments, получает информацию о комментариях и отображает ее в консоли. Для каждого комментария выводятся его ID и Email
